My day-to-day work covers debugging Rust crates, designing and tuning database schemas, and turning system data into decisions through analytics.

A comprehensive monitoring and project management platform for beneficiaries of the DOST SETUP iFund Program. Developed as a thesis project.

- **Tech stack:** Tauri v2, React, TypeScript, Supabase, Twilio
- **Impact:** Digitizes the tracking of financial assistance and compliance for MSMEs, including GIS-based analysis and regression-driven performance prediction.
- **Challenge:** Overcoming cross-platform compilation hurdles for Android and implementing real-time tracking features.
- **Repository:** [ASENXO-WEB_Fork](https://github.com/just-aldrin/ASENXO-WEB_Fork)
